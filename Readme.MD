Este repositório contém o código-fonte do meu portfólio profissional, desenvolvido para apresentar minha trajetória, minha stack de tecnologias e os principais projetos que venho construindo na área de desenvolvimento web.

🔗 **Acesse o projeto online:** [https://portfolio-devefrens.vercel.app](https://vercel.app)

---

## ✨ Funcionalidades e Destaques

- **Hero Section com Vídeo e Glassmorphism:** Fundo dinâmico com vídeo em loop, efeito de desfoque (`backdrop-filter`) e destaque visual com *glow* na foto de perfil.
- **Renderização Dinâmica de Projetos:** Os cards de projetos são gerados automaticamente via JavaScript a partir de uma lista estruturada de objetos.
- **Paginação Automática:** Sistema inteligente em JavaScript puro que exibe os projetos em uma grade centralizada de 4 cards e cria os controles de paginação automaticamente ao ultrapassar esse limite.
- **Layout Responsivo:** Grade adaptável utilizando CSS Grid e Flexbox para funcionar bem em desktops, tablets e smartphones.
- **Seção de Contato Integrada:** Acesso direto às redes profissionais e e-mail utilizando Bootstrap Icons.

---

## 🛠 Tecnologias Utilizadas

- **HTML5** — Estruturação semântica das seções.
- **CSS3** — Estilização moderna com variáveis CSS, CSS Grid, Flexbox, gradientes e animações suaves.
- **JavaScript (ES6+)** — Manipulação do DOM, renderização dinâmica de cards e lógica de paginação.
- **Bootstrap Icons** — Ícones vetoriais para links de contato e redes sociais.
- **Vercel** — Hospedagem e deploy contínuo (CI/CD).

## 🚀 Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/devefrens/portfolio-devefrens.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd portfolio-devefrens
   ```

3. **Execute no navegador:**
   Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão **Live Server** no VS Code para visualizar com recarregamento automático.
